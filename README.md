# Code Analyzer for AI Agents

AI 코딩 에이전트가 저장소에서 변경 대상을 찾고 영향 범위를 검증하는 과정을 재현 가능한 정적 graph로 근사한다. 탐색 비용, potential zone of effect, verification accessibility와 그 구조적 병목을 근거와 함께 제공하는 것이 목표다.

- [AGENTS.md](AGENTS.md), [CLAUDE.md](CLAUDE.md): 저장소에서 작업하는 AI 에이전트의 공통 규칙
